Check three things

1. At **0%**, the final value is **$1,000**.
2. At **8%**, it rounds to **$1,469**.
3. At **20%**, it rounds to **$2,488**.

The line and final value should update together. The chart scale should not jump when you move the slider.


If anything looks wrong, tell the agent. For example,

```text
At 0%, the total is not $1,000. Please check the formula.
```
