In this tutorial we'll make a small explanation of **compound growth**.

Try the live mockup on the right - this is what we'll be building. Move the slider from 8% to 12%. Note how small changes become larger differences over five years.

Together we'll build this as a Vividly slide then preview it locally and publish it with GitHub Pages.

## Before you begin

- You'll need [Python 3.12 or later](https://www.python.org/downloads/) and either [uv](https://docs.astral.sh/uv/getting-started/installation/) or [pipx](https://pipx.pypa.io/latest/how-to/install-pipx.html) installed.
- A coding agent that can read and edit a local workspace.
- A modern browser.
- To publish: [Git](https://git-scm.com/downloads), a [GitHub account](https://github.com/signup), an empty repository you can push to, and access to its Pages settings.

<summary>Installing Prerequisites</summary>

## Need Python?
Install Python 3.12 or later using the [official Python downloads page](https://www.python.org/downloads/), then open a new terminal. On Linux, use your distribution's package manager if a compatible version is available.

Check the installed version with `python3 --version` on macOS or Linux, or `py --version` on Windows. The version should be 3.12 or later.

## Need uv?
Install uv using its [official installation guide](https://docs.astral.sh/uv/getting-started/installation/), then open a new terminal.

## Need pipx?
Install pipx using its [official installation guide](https://pipx.pypa.io/latest/how-to/install-pipx.html), then open a new terminal.
