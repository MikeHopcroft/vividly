Vividly targets a fully agentic experience. Let your agent handle setup and get straight
to making something. You direct the story; your agent builds the presentation.

## Give your agent a starting brief

Open your coding agent in a folder where you keep projects. Use a mode that can read
documentation, run commands, and edit files. Copy the prompt below, changing the
project name and creative brief to suit your idea.

```text
Set up a Vividly project named "growth-demo" using this guide:
https://mikehopcroft.github.io/vividly/reference/agentic-bootstrap.md

Create a presentation with one interactive slide about annual compound growth: start with
$1,000, no further deposits, and show years 0 through 5. Include a
0%-20% growth-rate slider, initially 8%, a line chart, and the final
value. Keep the chart scale fixed from $1,000 to $2,500.
```

Review any installation requests your agent presents.

Use the example brief or substitute your own idea. When your agent reports that the
presentation is ready, open its preview link and try the interactions. Focus on
whether it communicates your idea and works as intended, not whether it looks like
our example.

## Refine what you see

Describe the change you want rather than prescribing the code. For example:

```text
Make the effect of changing the rate easier to see. Keep a dashed 8%
reference curve visible while I move the slider, and label both curves.
Keep the chart scale fixed.
```

## Prepare to share

When you are happy with the result, ask your agent to help with the next stage:

```text
Help me share this presentation on GitHub Pages.
```
